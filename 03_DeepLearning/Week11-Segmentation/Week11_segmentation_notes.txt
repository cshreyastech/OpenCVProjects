Semantic Segmentation
----------------------
Image Classification assigns a class label to the entire image.
Object Detetion finds and assigns a calss label to a bounding box.
Semantic Segmentation assigns a class label for every pixel.

Semantic Segmentation:
Input Image, Class labels, Output image, Number of Intensity = Number of Class Label

Instance Segmentation: No information about background

Panoptic Segmentation: Combination of Instance Semantic segmentation and Instance segmentation. Instances of same class and no pixels without labels.

Evaluation Matrics
------------------
Assumptions: 
  - K  + 1 classes, k regular classes + 1 Background class
  - pij -> amount of pixel of class i inferred to belong to class j.
  - Acuuracy = TP / (TP + FN)

1. Pixel Accuracy (PA) is computed as a ratio between the amount of properly classified pixel pii and 
  the total number of them.
2. Mean Pixel accuracy (mPA): is the ratio of correct pixel computed on a per-class basis and then averaged 
  over the total number of classes K+1.
3. Mean Intersection Over Union (mIOU) is calculated as a ratio between the number of true positives, 
  false positives, and false negatives for every class and then averaged across all classes.
  I0U = TP / (TP + FP + FN).
4. Dice Coefficient(F1 Score) is the doubled numer of true positives divided by the total number of pixels in 
  both ground truth and predicted segmentation masks.
  Dice = 2 * TP / (2 * TP + FP + FN)

Semantic Segmentation Arcitectures
----------------------------------
11.1) Semantic Segmentor
------------------
Segmentation = What + Where
What -> Solved by image classification. This needs context. Conv layer (extract information) followed by max pooling(combine them). 
  While capture What, we lost info needed for where. 
  - Conv layer extracts the information
  - Pooling layer combine in finding the context (What)

Where -> 
This need object viewed at multiple scales. Multi scale context
To solve this below approaches can be followed
Naive approach
1) Image Pyramids: Train at different scale
2) Encoder-Decoder: 
  - Similar architecture as  Classification
  - Downsample and Upsample(Segmentation map at orgional size)
    - Upsample takes information not only from lowest feature map but also from freature map at same resolution.
3) Dilated Convolution : 
  - In image classification downsampling is done to get the context.
  - Change convolution kernel. Increases context without changing the weights.
4) Spatial Pyramid Pooling
  - Object feature map captured at different scale
  - They are combined to form a larger feature map

11.2) Dilated Convolution / AKA Atrous Convolution
-------------------
- Dilation Convolution is used when we want to increase the receptive field of Kernel without increasing its size.
- Useful to analyze an image at different scale
- Reseptive field: Input window size of the kernel that governs the output
- Increasing the reseptive field will also increase the computation, so zeros are used.
- Increase the reseptive field by adding zeros (Dilation)
- Dilation rate: Number of cells that have to jumped to get the next non-zero filter value
- Increase the context without changing weights by adding zeros.
- No need for downsampling
- Disadvantage: Dilation leads to approximation
- Useful to analyze an image at different scale

3) Transposed Convolution (Deconvolution)
-------------------------
- It is used to up-sample an image or a feature vector in neural Network.
- Increase the size of the image given a kernel

4) Fully Convolution Net (FCN)
------------------------
- One of the first Deepleaning based segmentation architecture
- Used for changing the FCN to CN just by changing the number of filters. 
  CNN 7x7x512 > FCN (filter size 7 x 7, number of filters 4096) -> O/P FCN 1 x 1 x 4096
- Modify image classification networks as the backbone
- Replace the fully connected layer by convolution layers (Convolution, Max pool, activation(Relu))
- Use skip connections and deconvolution blocks to combine information at different resolution
- Convert FCN -> CONV Layer: This is done by adding number of filters
  - (7, 7, 512) -> use 4096 filters -> output (1, 1, 4096).
    - Total input / neuron: 7 x 7 x 512 = 25088
    - Parameter count : 25088 X 4096 + 4096 (bias)

- Convert Convolution(CONV) Layer to Fully Connected Layer (FCN)
  - (1, 1, 4096) -> filter size 7x7x512, number of filters 4096 (filter size should be same as depth of the tensor) 
    -> outputs Conv 7x7x512
- 1x1 Convolution is the same as 7x7 convolution. It is often used to change the depth of the network.
5) U-Net Segmentation architecture
----------------------------------
- Initally applied to biomedial images
- Inspired by the FCN network
- U-Net by design is approximately symmetric
- Learns boundaries of the same class
- Uses a tiling strategy for very large images
- Requires very few training examples
- Overlap-tiling
  - Data augmentation
    - Size
    - Color
    - Affine Transform
    - Non-linear Transformation
- Loss function
  - Boundary penality

6) SegNet Segmentation architecture
------------------------------------
- Architecture is similar to U-Net
- Uses VGG-16 backbone
- Different upsampling strategy
  - Requires less memory
- Unet the O/P feature map was feed during upsampling. It was concatinated with the feature map. 
  This copy is very memory intensive.
- Segnet doest not copy all information from the feature map. It uses pooling indices. 
- Pooling Indices
  - Pass just oputput of max pooling indices. so less values and just pass indices
  - Lets take max pooling. Pass indices(int) instead of values which is in float
  - Feature map passess max pooling indices: Both the dimention is reduced and indices(int) instead of value(float)
    - This reduces memory footage drastically.
  - In the Upsample step pooling indices are used to Upsample. 

7) DeepLab Segmentation architecture
------------------------------------
- Use VGG-16 backbone
- Replace some convolution filters by dilated convolution filters
- Use Conditional Random Fields(CRF) to ensorce spatial consistency (removed from v3)
- Dilated Convolution: Its adding holes in the filter to increase the receptive field of the convolution kernel.
- Y gradient filter: forms a heat map
