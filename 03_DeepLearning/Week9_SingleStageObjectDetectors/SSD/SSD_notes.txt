Single Shot Multibox Detector (SSD)
-----------------------------------
- Default Bounding boxes: Check if default bounding box contains an object or not. It is not responsible for idenitying other objects
    - Handling Scale Variation
    - Handling Aspect Ratio
    - Detector + classifier
        - c+ 4 where 4 is this the coordinates of the BBox being trained
        - 21 -> 20 classes + 1 class for background
        - Understing one row of the tensor (1 x 1 x 150)
            - 1 to 25 bins correspondes to default box 
                - 1 to 4 -> dx, dy, dw, dh -> Position of default box are fixed
                - 5 to 25 -> class 1 to 20 + background
            - there are 6 boxes: 6 * 25 = 150
        - 19 x 19 x 6 BBoxs = 19*19*6 = 2166 total bounding boxes
- Training
- Loss function
    - Classification Loss (detected class and the actual ground truth class)
    - Localization Loss (detected class and the actual ground truth class)
- Class imbalance problem
    - If we compute the cross entropy loss for every pick cell, the network will try to predict background class as overvelmping number of patches will be background class.
To solve this SSD uses Hard mining procedure to select only hard example of background pixcels. Then use cross entropy loss on the backgroud pixels which are hard. The example are let go, like smooth surfaces, no edges which has no textures.

Pros
    - Accuracy comparable to Faster R-CNN
    - Speed comparable to YOLO
Disadvantage
    - Bounding boxes predicted by earlier layers may not be very reliable
    - Hard-example mining is a hard trick to use. For various tasks, we should take different hyper parameters of hard example mining.
