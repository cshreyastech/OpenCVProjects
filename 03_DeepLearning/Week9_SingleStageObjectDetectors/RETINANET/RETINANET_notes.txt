RETINANET
---------
Focus on things which you are not good at.
Biggest challege in Single shot detectors was huge class imbalance with most of the pixels to be Background and small part to be object class.

The huge class imbalance is addressed changing loss function.
Focal Loss:
FL(pt) = -(1 - pt)^gamma * log(pt)
when pt ~ 1 that is model is able to predict correct easily, p^gamma is a very small number. So easy examples are weighted lot less than the hard examples.
Focal loss focus on hard examples than easy examples.
Feature pyramid network

Summary
--------
- Focal loss addressed the class imbalance problem.
- Used hierarichical structure of convnets to create feature maps.
- Improved feature map at every scale using information from deeper layers.
- Improved accuracy.
- Similar performance to SSD.
